## Contribution and review

Original PR: https://github.com/loryanstrant/HA-HidrateSpark-Bluetooth-Proxy/pull/12
Original commit: `d30a893093ce08f3269223795225e149913ec718` (unchanged ancestor).
The complete modified implementation and test files were read before execution.
The contribution adds name-based identity/address following, automatic migration with
fixed device keys, GATT-path selection, connection keepalive/recovery, metadata, and
sip-frame weight/refill handling. Follow-up fixes and extra tests are separate from
the original contribution. README, changelog and release notes credit/thank kbaker827
and label PRO 2 experimental. ADR-0001 records the compatibility decisions.

Independent consultant review was used as a second opinion, not as verification.
Confirmed issues were reproduced by failing tests before being fixed: unusable weight
pairs affecting fill, rejected sips learning calibration, empty fill restoring as full,
refill-source deduplication lost on restart, and manual/address discovery duplicates.
Other speculative hardware/protocol suggestions were not adopted.
